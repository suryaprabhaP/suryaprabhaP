### 🚀 Featured Projects

#### 🛡️ [KSP Drishti AI: Crime Intelligence & Multi-Agent Command Platform](https://github.com/suryaprabhaP/drishti_final)
AI crime-intelligence platform for **Karnataka State Police**. An orchestrator routes officer queries to specialist agents for **deterministic SQL analytics (DuckDB)**, **DBSCAN hotspot clustering** with convex-hull checkpoint planning, **BFS-based syndicate network analysis**, and **Kannada/English voice forensics**. Every action is recorded in a **SHA-256 hash-chained audit log** (Section 65B, BSA 2023).
`Python` `Flask` `React` `DuckDB` `DBSCAN` `Graph Analytics` `Zoho Catalyst` `Groq` `Sarvam AI`

#### 🏛️ [MITRA: Multilingual Multi-Agent Civic Intelligence Platform](https://github.com/suryaprabhaP/mitra-frontend)
Helps citizens discover welfare schemes, process documents, and resolve grievances in **22+ Indian languages**. Six microservices: an LLM intent-routing gateway, a **grievance agent with SLA-based auto-escalation**, an **OpenCV document pipeline**, an autonomous **monitoring agent** (observe → reason → act → remember), and an **IVR voice booking agent** over phone calls.
`FastAPI` `Express` `React` `Sarvam AI (STT/TTS/LLM)` `Exotel` `OpenCV` `Tesseract OCR`

#### 🔬 [AquaPlastix: Polarized-Imaging Microplastic Analyzer](https://github.com/CH3MLON/Aquaplastix) *(patent filed)*
Edge AI system that classifies microplastics (**LDPE, PE, PHA, PS**) using a fine-tuned **ResNet-50** with **CLAHE** preprocessing and 5-fold cross-validation, deployed on a Raspberry Pi.
`TensorFlow` `ResNet-50` `OpenCV` `Raspberry Pi` `Roboflow`
